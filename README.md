# Local_Kart

This is a web application for local vendors and small shopkeepers.
In this website, we have made a project to help local shopkeepers sell their products online to nearby customers.

## Features
- Customer page with product search, shopping cart, total calculation, and checkout
- Vendor portal page for store registration and listing products

## Tech Stack
- HTML
- CSS
- JavaScript

## Project Files
- `index.html` - Customer store page
- `vendor.html` - Vendor registration and product listing page
- `README.md` - Project overview
